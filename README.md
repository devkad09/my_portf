# Portfolio Project

A modern, responsive portfolio website built with React, Vite, TypeScript, and Tailwind CSS. Featuring glassmorphism design, ambient background effects, and smooth reveal animations.

## 🚀 Technologies Used

- **React** - UI Framework
- **Vite** - Build Tool
- **TypeScript** - Language
- **Tailwind CSS** - Styling
- **Shadcn UI** - Component Library
- **Lucide React** - Icons
- **Radix UI** - Primitive Components

## ✨ Features

- **Hero Section** - High-impact introduction
- **About Me** - Detailed background information
- **Skills** - Technical expertise showcase
- **Education** - Academic history
- **Projects** - Portfolio of work
- **Services** - Offerings and capabilities
- **Contact** - Functional contact form
- **Responsive Design** - Optimized for all devices
- **Ambient Background** - Dynamic visual effects
- **Scroll Reveal** - Engaging entrance animations

## 🛠️ Getting Started

### Prerequisites

- Node.js (Latest LTS version recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## 🏗️ Building for Production

To create an optimized production build:

```bash
npm run build
```

The output will be generated in the `dist` folder.

## 📁 Project Structure

- `src/components` - Reusable UI components
- `src/pages` - Page-level components
- `src/hooks` - Custom React hooks
- `src/lib` - Utility functions and libraries
- `public` - Static assets
